# Certum Studio

Interne cockpit van Bureau Certum voor het ontwikkelen van professionele trainingen en praktijksimulaties.

Productvisie, architectuur en werkafspraken: zie [CLAUDE.md](CLAUDE.md).

## Lokaal draaien

```bash
npm install
npm run dev
```

Open daarna http://localhost:3000.

## Overige commando's

```bash
npm run build   # productiebuild
npm run lint    # ESLint
```
